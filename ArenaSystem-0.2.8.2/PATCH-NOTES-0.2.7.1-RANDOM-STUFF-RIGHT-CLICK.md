# Patch Notes 0.2.7.1 — Random Stuff Right-Click

- Random Stuff sekarang digunakan dengan klik kanan (RIGHT_CLICK_AIR atau RIGHT_CLICK_BLOCK).
- Interaksi vanilla pada item ditahan ketika Random Stuff digunakan agar klik kanan tidak melempar, menempatkan, atau mengaktifkan fungsi item aslinya.
- Klik kiri tidak lagi mengaktifkan Random Stuff.
- Lore item dan README diperbarui agar instruksi sesuai dengan kontrol yang benar.
