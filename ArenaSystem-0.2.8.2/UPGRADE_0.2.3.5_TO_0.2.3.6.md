# Upgrade ArenaSystem 0.2.3.5 → 0.2.3.6

1. Backup world, folder `plugins/ArenaSystem`, dan snapshot arena.
2. Ganti JAR lama dengan `ArenaSystem-0.2.3.6.jar`.
3. Restart server sepenuhnya.
4. Tidak ada perubahan format konfigurasi.

Di 0.2.3.6, item skill dapat diaktifkan dengan klik kanan di udara/area kosong maupun saat menghadap blok. Untuk Sniper Mark dan Boxer Uppercut, arahkan pandangan ke lawan yang ingin ditargetkan; skill tersebut tidak membutuhkan blok.
