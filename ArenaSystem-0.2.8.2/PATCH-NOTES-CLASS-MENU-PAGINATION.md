# Class Menu Pagination — Patch Notes

- The TDM preparation class selector now has two pages.
- Page 1: Knight, Tank, Archer, Sniper.
- Page 2: Assassin, Ninja, Boxer, Demoman.
- Each page uses class-card slots 10, 12, 14, and 16, with a one-slot visual separator between neighboring cards.
- Previous is in slot 18, the page indicator is in slot 22, and Next is in slot 26.
- Class cards are mapped by the inventory holder, so page 2 selections resolve to the correct class.
- Click and drag operations are cancelled while the selector is open.
- Existing class abilities and cooldown settings are unchanged by this UI-only patch.
