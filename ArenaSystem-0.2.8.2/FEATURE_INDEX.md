# Feature Index

1. **Arena System:** Radius-based generation, normalization, snapshotting, and reset (`ArenaGenerator.java`, `TerrainNormalizer.java`).
2. **Team Management:** Dynamic generation for RED, BLUE, GREEN, YELLOW teams (`MatchManager.java`).
3. **Match Modes:** Team Deathmatch (TDM) and Relic Rush (`MatchState.java`, `RelicListener.java`).
4. **Class System:** 8 TDM classes (Knight, Tank, Archer, Sniper, Assassin, Ninja, Boxer, Demoman) with active/passive skills (`ClassAbilityListener.java`, `ClassPassiveManager.java`).
5. **Special Systems:** Death Camera, Random Stuff (Pocket Bomb, Blast Mine, Shadow Veil, Sniper Mark, Aim Lock, Boxer Heavy Jab).
