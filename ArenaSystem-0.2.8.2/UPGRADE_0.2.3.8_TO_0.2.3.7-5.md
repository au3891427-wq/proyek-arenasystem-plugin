# Upgrade ArenaSystem 0.2.3.8 → 0.2.3.7-5

1. Matikan server dengan `stop`.
2. Backup folder `plugins/ArenaSystem`, data arena, dan snapshot.
3. Ganti JAR lama dengan `ArenaSystem-0.2.3.7-5.jar`; jangan memasang dua JAR ArenaSystem sekaligus.
4. Nyalakan server dan uji skill Ninja selama pertandingan TDM.

## Kontrol skill
- **F**: skill utama class.
- **Ninja F**: Smoke Bomb.
- **Ninja Shift+F**: Shadow Step; Shift boleh di-bind sebagai Sneak atau Sprint.
- Klik kanan item skill tetap tersedia sebagai alternatif.
