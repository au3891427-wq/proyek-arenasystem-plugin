# Class Selector Pagination — Pemeriksaan Mandiri

Lakukan langkah berikut di lobby persiapan TDM. Satu akun sudah cukup.

## Class selector

1. Open the class selector using the lobby compass.
2. Page 1 should show Knight, Tank, Archer, and Sniper in slots 10, 12, 14, and 16. There should be one separator slot between neighboring class cards.
3. Click Next in slot 26. Page 2 should show Assassin, Ninja, Boxer, and Demoman in the same card slots.
4. Click Previous in slot 18. The menu should return to page 1.
5. The page indicator in slot 22 should show the current page out of two.
6. Select a class from either page. The selection should be saved, the inventory should close, and the match HUD should update.
7. Try clicking or dragging items from the menu and the player inventory. No menu item should move into the player's inventory.
8. Close the menu and reopen it with the lobby compass. It should open at page 1.

## Catatan build

Kompilasi Paper penuh tetap perlu dipastikan pada lingkungan build yang sesuai.
