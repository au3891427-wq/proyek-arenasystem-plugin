# Upgrade 0.1.0 → 0.2.0

1. Stop the Minecraft server normally.
2. Back up the active world and the full `plugins/ArenaSystem/` data folder.
3. Remove the old `ArenaSystem-0.1.0.jar` from the active plugins directory.
4. Build and install `ArenaSystem-0.2.0.jar` on Paper 26.3 / Java 25.
5. Start the server and check the log for successful plugin enable.
6. Run `/arena list` and `/arena info <nama>` to inspect old arena entries.

The existing `config.yml` arena metadata is still readable. However, arenas generated by 0.1.0 do not have the 0.2.0 compressed original-block snapshot. For that reason, the new `delete` and `regenerate` commands refuse to modify those legacy arenas. Restore those areas from a world backup instead.

New arenas created in 0.2.0 get a snapshot under `plugins/ArenaSystem/snapshots/`. Keep the snapshot file paired with its world and arena config; they are a recovery set.
