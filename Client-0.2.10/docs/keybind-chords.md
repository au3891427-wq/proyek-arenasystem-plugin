# Mengatur kombinasi tombol ArenaSystem

1. Buka **Options → Controls → Key Binds**.
2. Klik binding ArenaSystem yang ingin diubah.
3. Tahan `Shift`, `Ctrl`, dan/atau `Alt`, lalu tekan tombol utama (atau klik tombol mouse).
4. Daftar Controls akan menampilkan kombinasi, misalnya `Ctrl + Shift + K`.
5. Tekan `Esc` saat binding sedang dipilih untuk menghapus binding; modifier-nya ikut direset ke kosong.
6. Tombol **Reset All** mengembalikan tombol dan modifier ArenaSystem ke default.

Modifier yang didukung: Shift, Ctrl, dan Alt. Kombinasi kiri/kanan untuk modifier yang sama dianggap satu jenis.

Konfigurasi modifier disimpan di `config/arenasystem-keybinds.json`. Tombol utama tetap disimpan oleh Minecraft di `options.txt`.
